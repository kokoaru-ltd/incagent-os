# SCRIPTS KNOWLEDGE BASE

## OVERVIEW

Standalone automation scripts for posting, Freelancer workflow, ringi image rendering, and skill acquisition.

## WHERE TO LOOK

| Task | Location | Notes |
| --- | --- | --- |
| Freelancer search/proposal | `freelancer_worker.py` | Use dry-run/draft mode first. |
| X posting | `post_to_x.py` | External publish surface. |
| Ringi card image | `render_ringi_card.py` | Local image generation. |
| Skill acquisition | `skill_acquire.py` | Scans candidate skills before adoption. |

## CONVENTIONS

- Run syntax checks before changing scripts.
- Prefer dry-run or local artifact output over real posting, bidding, or API writes.
- Treat any token required by these scripts as secret. Check presence only, never print values.
- `__pycache__` exists here; do not edit generated bytecode.

## ANTI-PATTERNS

- Do not post to X, bid on Freelancer, or contact external services without approval.
- Do not weaken security scanning in `skill_acquire.py`.
- Do not make scripts depend on secrets hardcoded in files.

## COMMANDS

```bash
python3 -m py_compile scripts/*.py
python3 scripts/post_to_x.py --dry-run
python3 scripts/freelancer_worker.py --dry-run
python3 scripts/skill_acquire.py "プレゼン スライド 作成"
```
